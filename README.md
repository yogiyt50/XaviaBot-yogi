المتطلبات

• NodeJS الإصدار 16.x

التثبيت

• تثبيت Yogi على Replit: شاهد الشرح عبر يوتيوب

• استيراد المشروع إلى:

Replit

Glitch


أو

• تحميل المشروع بصيغة ZIP أو استنساخه باستخدام الأمر التالي:

git clone https://github.com/XaviaTeam/XaviaBot.git

• الانتقال إلى مجلد المشروع

cd xavia

• استخدم أداة c3c-fbstate لاستخراج appstate من حسابك على فيسبوك ثم قم بلصقه داخل ملف appstate.json

• تثبيت المتطلبات وتشغيل البوت

npm install && npm start
